Une même fièvre, six foyers : le HTML corrigé

Le code de chaque épisode, sans la balise </div> en trop qui cassait la mise en page. La carte et les icônes sont intactes.

  1. Cliquez sur Copier le HTML.
  2. Dans Elementor, collez le code dans un widget HTML et supprimez l’ancien Éditeur de texte.
  3. Sur le widget HTML : Avancé → Largeur → Par défaut, puis Mettre à jour.
